# 📊 Small Business Bookkeeping Dashboard

## Overview
This project simulates financial tracking and analysis for a small service-based business. The dashboard was built to monitor income, expenses, and overall profitability.

## Tools Used
- Microsoft Excel
- Data Cleaning & Formatting
- Financial Analysis

## Key Metrics
- Total Revenue
- Total Expenses
- Net Profit

## Dashboard Preview
![Dashboard](dashboard.png)

## Key Insights
- Revenue remained consistent with noticeable peaks mid-month
- Supplies represented the highest expense category
- Marketing spend did not significantly increase revenue
- The business maintained strong overall profitability

## What I Learned
- How to structure financial data for analysis
- How to build clean, professional dashboards in Excel
- How to present insights clearly for decision-making
